## API Compatibility

### Memory Operations

Hystersis maintains API compatibility with Mem0 v3 for core operations:

```python
# Mem0 v3
from mem0 import Memory
m = Memory()
m.add("I prefer dark mode", user_id="alice")

# Hystersis equivalent
from hystersis import Hystersis
client = Hystersis(api_key="your-key")
client.create_memory(
    content="I prefer dark mode",
    user_id="alice"
)
```

### Search Operations

```python
# Mem0 v3
results = m.search("dark mode preferences", user_id="alice")

# Hystersis equivalent
results = client.search(
    query="dark mode preferences",
    user_id="alice"
)

# Hystersis also supports enhanced search
results = client.search_enhanced(
    query="dark mode preferences",
    user_id="alice",
    mode="spreading"
)
```

### Entity Operations

```python
# Mem0 v3
m.add("Alice works at TechCorp", user_id="alice", metadata={"type": "work"})

# Hystersis equivalent
client.create_memory(
    content="Alice works at TechCorp",
    user_id="alice",
    metadata={"type": "work"}
)
```

## Migration Guide

### 1. Export from Mem0

```python
from mem0 import Memory

m = Memory()
memories = m.get_all(user_id="alice")
entities = m.get_all_graph_entities(user_id="alice")
```

### 2. Import to Hystersis

```python
from hystersis import Hystersis

client = Hystersis(api_key="your-key")

# Import memories
for memory in memories:
    client.create_memory(
        content=memory["memory"],
        user_id=memory["user_id"],
        metadata=memory.get("metadata", {}),
        created_at=memory.get("created_at")
    )

# Import graph entities
for entity in entities:
    client.create_entity(
        name=entity["name"],
        type=entity["type"],
        user_id=entity["user_id"]
    )
```

### 3. Update Configuration

```bash
# Replace Mem0 environment variables
# OLD: MEM0_API_KEY=...
# NEW: HYSTERESIS_API_KEY=...

# Update API endpoints
# OLD: https://api.mem0.ai/v1/
# NEW: https://api.hystersis.com/
```

## Hystersis Enhancements

After migration, enable Hystersis-specific features:

```python
# Enable compression
client.set_compression_mode("extract")

# Enable tiered memory
client.set_tier_policy("balanced")

# Use spreading activation search
results = client.search_enhanced(
    query="user preferences",
    mode="spreading"
)

# Use skills system
skill = client.create_skill(
    name="preference-extractor",
    trigger="user mentions a preference",
    action="Extract and store the preference with high priority"
)
```
