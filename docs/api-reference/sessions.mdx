# Sessions API

Sessions group related messages and memories within a single agent interaction. They provide context windowing and real-time multi-agent sync.

## Create Session

`POST /sessions`

```bash
curl -X POST https://api.hystersis.ai/sessions \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "assistant-bot",
    "user_id": "alice",
    "metadata": {
      "purpose": "customer-support",
      "channel": "chat"
    }
  }'
```

**Body Parameters**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `agent_id` | string | Yes | Identifier of the agent |
| `user_id` | string | No | Associated user |
| `metadata` | object | No | Arbitrary session metadata |

**Response** `201 Created`

```json
{
  "id": "sess_xyz789",
  "agent_id": "assistant-bot",
  "user_id": "alice",
  "metadata": {
    "purpose": "customer-support",
    "channel": "chat"
  },
  "created_at": "2024-01-15T10:00:00Z"
}
```

## Get Session

`GET /sessions/{id}`

```bash
curl https://api.hystersis.ai/sessions/sess_xyz789 \
  -H "X-API-Key: your-key"
```

## List Sessions

`GET /sessions`

```bash
curl "https://api.hystersis.ai/sessions?agent_id=assistant-bot&page=1" \
  -H "X-API-Key: your-key"
```

---

## Add Message

`POST /sessions/{id}/messages`

Append a message to the session. Messages are persisted and used to build session-scoped memory context.

```bash
curl -X POST https://api.hystersis.ai/sessions/sess_xyz789/messages \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "user",
    "content": "I need help debugging my Python script"
  }'
```

**Body Parameters**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `role` | string | Yes | `user`, `assistant`, `system` |
| `content` | string | Yes | Message text |
| `metadata` | object | No | Tool calls, function results, etc. |

**Response** `201 Created`

```json
{
  "id": "msg_001",
  "session_id": "sess_xyz789",
  "role": "user",
  "content": "I need help debugging my Python script",
  "timestamp": "2024-01-15T10:01:00Z"
}
```

---

## Get Messages

`GET /sessions/{id}/messages`

```bash
curl "https://api.hystersis.ai/sessions/sess_xyz789/messages?limit=50" \
  -H "X-API-Key: your-key"
```

Returns messages in chronological order with pagination.

---

## Delete Session

`DELETE /sessions/{id}`

Soft-deletes the session. Session memories and messages are retained but excluded from active retrieval.

---

## Session Memory Context

When a session is active, Hystersis automatically:

1. Retrieves the most relevant long-term memories for the session user
2. Incorporates recent session messages as short-term context
3. Auto-extracts facts from messages into the memory pipeline at session end

This context window is available via:

```bash
GET /sessions/{id}/context
```

---

## Real-Time Sync

For multi-agent scenarios, sessions support real-time memory sync via WebSocket:

```bash
ws://api.hystersis.ai/sessions/{id}/sync
```

Any memory write by one agent is immediately pushed to all agents subscribed to the same session.

## SDK Examples

```python
session = client.create_session(agent_id="my-agent")

client.add_message(
    session_id=session["id"],
    role="user",
    content="What's my Python version?"
)

messages = client.get_messages(session["id"])
```

```typescript
const session = await client.sessions.create({
  agentId: 'my-agent',
  userId: 'alice'
});

await client.messages.add(session.id, 'user', 'Hello!');

const messages = await client.sessions.getMessages(session.id);
```
