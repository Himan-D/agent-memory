# Memories API

## Create Memory

`POST /memories`

Store a new memory.

**Request**

```bash
curl -X POST https://api.hystersis.ai/memories \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "User prefers dark mode and uses VS Code",
    "type": "user",
    "user_id": "alice",
    "category": "preferences",
    "tags": ["ui", "editor"],
    "importance": "high"
  }'
```

**Body Parameters**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content` | string | Yes | Memory text |
| `type` | string | No | `conversation`, `session`, `user`, `org` (default: `conversation`) |
| `user_id` | string | No | Owning user |
| `org_id` | string | No | Organization scope |
| `agent_id` | string | No | Originating agent |
| `session_id` | string | No | Source session |
| `category` | string | No | Free-form label |
| `tags` | array | No | Searchable string tags |
| `importance` | string | No | `critical`, `high`, `medium`, `low` (default: `medium`) |
| `immutable` | bool | No | Prevent updates (default: false) |
| `expiration_date` | string | No | ISO 8601 expiry timestamp |
| `metadata` | object | No | Arbitrary key-value pairs |

**Response** `201 Created`

```json
{
  "id": "mem_abc123",
  "content": "User prefers dark mode and uses VS Code",
  "type": "user",
  "user_id": "alice",
  "category": "preferences",
  "tags": ["ui", "editor"],
  "importance": "high",
  "status": "active",
  "version": 1,
  "access_count": 0,
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-01-15T10:00:00Z"
}
```

## List Memories

`GET /memories`

List memories with optional filters.

```bash
curl "https://api.hystersis.ai/memories?user_id=alice&type=user&page=1&page_size=20" \
  -H "X-API-Key: your-key"
```

**Query Parameters**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user_id` | string | Filter by user |
| `type` | string | Filter by memory type |
| `category` | string | Filter by category |
| `importance` | string | Minimum importance level |
| `status` | string | `active`, `archived`, `deleted` |
| `page` | int | Page number (default: 1) |
| `page_size` | int | Results per page (default: 20, max: 100) |

**Response**

```json
{
  "items": [...],
  "page": 1,
  "page_size": 20,
  "total_items": 142,
  "total_pages": 8,
  "has_more": true
}
```

## Get Memory

`GET /memories/{id}`

```bash
curl https://api.hystersis.ai/memories/mem_abc123 \
  -H "X-API-Key: your-key"
```

---

## Update Memory

`PUT /memories/{id}`

```bash
curl -X PUT https://api.hystersis.ai/memories/mem_abc123 \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "User prefers dark mode, VS Code, and Vim keybindings",
    "importance": "high"
  }'
```

Updates increment `version` and create a `MemoryVersion` snapshot. Immutable memories return `403`.

---

## Delete Memory

`DELETE /memories/{id}`

Soft-deletes the memory (status → `deleted`). The memory is excluded from search but retained for provenance.

```bash
curl -X DELETE https://api.hystersis.ai/memories/mem_abc123 \
  -H "X-API-Key: your-key"
```

## Memory Feedback

`POST /memories/{id}/feedback`

```bash
curl -X POST https://api.hystersis.ai/memories/mem_abc123/feedback \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"feedback_type": "positive"}'
```

Feedback types: `positive`, `negative`, `very_negative`. See [Memory Worth Scoring](/mw-scoring).

## Memory History

`GET /memories/{id}/history`

Returns the full version history for a memory.
