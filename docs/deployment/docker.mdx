## Prerequisites

- Docker 24+
- Docker Compose v2

## Single Container

```bash
docker pull hystersis/hystersis:latest

docker run -d \
  --name hystersis \
  -p 8080:8080 \
  -e OPENAI_API_KEY=sk-... \
  -e QDRANT_URL=http://qdrant:6333 \
  hystersis/hystersis:latest
```

## Docker Compose

```yaml
version: "3.9"
services:
  hystersis:
    image: hystersis/hystersis:latest
    ports:
      - "8080:8080"
    environment:
      OPENAI_API_KEY: ${OPENAI_API_KEY}
      QDRANT_URL: http://qdrant:6333
      NEO4J_URI: bolt://neo4j:7687
    depends_on:
      - qdrant
      - neo4j

  qdrant:
    image: qdrant/qdrant:latest
    volumes:
      - qdrant_data:/qdrant/storage

  neo4j:
    image: neo4j:5
    environment:
      NEO4J_AUTH: neo4j/password
    volumes:
      - neo4j_data:/data

volumes:
  qdrant_data:
  neo4j_data:
```
