# Compression Engine

The Hystersis compression engine is the primary performance differentiator over alternatives. It achieves **80–85% token reduction** at **97%+ extraction accuracy** using the proprietary ProMem algorithm.

## Why Compression Matters

Storing raw conversation text verbatim is wasteful. A 10,000-token conversation may contain only 200 tokens of durable facts. Compression extracts the signal and discards the noise, enabling:

- Longer agent context without hitting token limits
- Faster semantic search over denser representations
- Lower storage and embedding costs

## ProMem Algorithm

ProMem (Proactive Memory Extraction) is a two-pass self-questioning algorithm:

### Pass 1: Extraction

1. **Self-Question** — Ask: "What are the key facts in this memory?"
2. **Extract** — Pull structured facts with confidence scores
3. **Verify** — Cross-check extracted facts against source content

### Pass 2: Gap Detection

1. **Gap Detection** — Identify questions the extracted facts cannot answer
2. **Active Filling** — Re-query the source content for missing critical information
3. **Supplement** — Merge gaps into the fact list

```
Input:  "Hey, I just got off a call with Sarah from the DevOps team.
         She mentioned they're planning to migrate from Kubernetes 1.24
         to 1.28 next quarter due to the security patches. She also
         said the staging cluster has been flaky lately."

Output: [
  {"fact": "DevOps team planning K8s 1.24→1.28 migration next quarter", "confidence": 0.97},
  {"fact": "Migration motivation: security patches", "confidence": 0.95},
  {"fact": "Staging cluster is unstable", "confidence": 0.91}
]
```

Token reduction: ~85% (350 tokens → 53 tokens)

## LLM Router

The LLM router classifies memory complexity and routes to the appropriate model:

| Route | Model | Trigger |
|-------|-------|---------|
| Fast | `gpt-4o-mini` | Complexity score < 0.6 |
| Verify | `claude-3-5-sonnet` | Complexity score ≥ 0.6 |

Complexity scoring considers:
- Content length
- Number of entities detected
- Presence of contradictions or ambiguity
- Temporal references

## Async Pipeline

Compression runs asynchronously to keep write latency under 5ms:

```
POST /memories
  → Store raw memory immediately (fast)
  → Enqueue compression task in Redis
  → Return memory ID to caller

Background worker:
  → Dequeue task
  → Run ProMem extraction
  → Update memory with compressed facts
  → Update Knowledge Graph
```

## Tiered Storage

Memories are automatically promoted/demoted across tiers based on access patterns:

| Tier | Description | TTL |
|------|-------------|-----|
| Working | Actively being referenced (in-session) | Session lifetime |
| Hot | Recently accessed (last 7 days) | 30 days |
| Cold | Infrequently accessed | 1 year |
| Archive | Low importance + no recent access | Indefinite |

## Configuration

```bash
COMPRESSION_ENABLED=true
COMPRESSION_LLM_FAST_PROVIDER=openai
COMPRESSION_LLM_FAST_MODEL=gpt-4o-mini
COMPRESSION_LLM_VERIFY_PROVIDER=anthropic
COMPRESSION_LLM_VERIFY_MODEL=claude-3-5-sonnet
COMPRESSION_COMPLEXITY_THRESHOLD=0.6
COMPRESSION_MODE=extract
TIER_POLICY=balanced
REDIS_URL=redis://localhost:6379
```
