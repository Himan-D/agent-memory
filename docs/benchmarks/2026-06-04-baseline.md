# Baseline Benchmark Results — 2026-06-04

## Setup

| Parameter | Value |
|-----------|-------|
| Embedding | `text-embedding-3-small` (1536d) |
| LLM Judge | `gpt-4o-mini` (F1 fallback on API error) |
| Vector Store | Qdrant (gRPC, port 6334) |
| Graph Store | Neo4j (bolt, port 7687) |
| Retrieval | Vector search (top-10, cosine) + keyword fallback (word-overlap) |
| Answer | Top-1 raw memory content (no synthesis) |
| Scoring | LLM-as-judge 0–100, fallback F1 word-overlap |
| Concurrency | 3 parallel questions |

## Results

| Dataset | Overall | Single-Hop | Multi-Hop | P50 Latency | P95 Latency | Tokens |
|---------|---------|-----------|----------|-------------|-------------|--------|
| LoCoMo | **0.83** | 0.89 | 0.65 | 1798ms | 2237ms | 9 |
| LongMemEval | **0.82** | 0.90 | 0.00* | 1713ms | 2217ms | 9 |
| ES-MemEval | **0.81** | 0.85 | 0.75 | 2488ms | 3317ms | 11 |
| BEAM 1M | **0.88** | 0.85 | 1.00 | 2753ms | 3410ms | 8 |

*\*LongMemEval multi-hop 0.00 due to category mapping: only `temporal_reasoning` (6/50 questions) maps to multi-hop; `knowledge_update`, `multi_session`, `old`, `new` are unmapped.*

## Comparison vs Mem0 (April 2026)

| Benchmark | Mem0 | Us | Gap |
|-----------|------|----|-----|
| LoCoMo | 91.6 | 83 | **8.6 pts** |
| LongMemEval | 94.4 | 82 | **12.4 pts** |
| BEAM 1M | 64.1 | 88 | **+23.9 pts** |

**Note**: Mem0 uses GPT-5 as judge + answer synthesis + multi-signal retrieval (semantic + BM25 + entity). We use `gpt-4o-mini` with top-1 raw content. BEAM comparison is unreliable due to small dataset (20 questions) and different scoring methodology.

## Key Differences vs Mem0 Pipeline

| Area | Mem0 | Us |
|------|------|----|
| Embedding | Qwen 600M (SageMaker) | text-embedding-3-small |
| LLM Judge | GPT-5 | gpt-4o-mini |
| Answer | Generated from retrieved memories | Top-1 raw content |
| Retrieval | Multi-signal fusion | Vector + keyword fallback |
| Temporal | Temporal reranking | Phase rotation + decay scoring |
| Tokens/query | ~7K | ~36 (9 tokens × 4 chars/token) |

## Pipeline Components Verified Working

- [x] OpenAI embedding generation → Qdrant vector search
- [x] LLM-as-judge scoring (`gpt-4o-mini`)
- [x] F1 word-overlap fallback scorer
- [x] Keyword graph fallback (stop-word filtered prefix matching)
- [x] Session-agnostic search (benchmark ignores sessionID, searches all memories)
- [x] Safety classifier (configurable via `MEMORY_SAFETY_ENABLED`)
